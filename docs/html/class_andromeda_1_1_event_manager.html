Detailed Description

High-performance, type-safe event distribution system.

  • The EventManager facilitates decoupled communication between engine components. Features:
  • Type Safety: Uses C++20 concepts to enforce correct event inheritance.
  • Performance: Optimized dispatch loop using deferred removal to avoid expensive heap allocations (vector copies) during event firing.
  • Reentrancy: Safe to add or remove listeners even while a dispatch is in progress.
