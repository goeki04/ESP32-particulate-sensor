Detailed Description

nlohmann::json (de)serialization support for GLM vector, matrix and quaternion types.

Including this header makes nlohmann::json able to convert vec2/vec3/vec4, mat3/mat4 and quat to and from JSON automatically via ADL (argument-dependent lookup), e.g. when a struct containing these types uses NLOHMANN_DEFINE_TYPE_NON_INTRUSIVE. Vectors/matrices are stored as plain JSON arrays; quaternions are stored as an object with named x/y/z/w fields.
