Inspector UI for the Material component: reflects the material's UBO fields into editable widgets.

Looks up the material via the ResourceManager and, if it exposes a UBO structure, uses the generated reflect() visitor to emit a widget per field (drag, slider or color picker depending on type and metadata). Matrix fields are skipped. Changed values are pushed back to the GPU via updateUBOData().

Parameters
handleHandle to the entity that owns the Material.
undoStateStorage for the pre-edit Material snapshot.

Inspector UI for the Transform component: position, rotation (degrees) and scale.

Rotation is presented in degrees for readability and converted back to a quaternion on edit. Each field snapshots the transform on activation and dispatches an OnPushUndoTransform event when the edit completes.

Parameters
handleHandle to the entity that owns the Transform.
undoStateStorage for the pre-edit Transform snapshot.

Renders the inspector UI for every supported component attached to an entity.

Iterates a compile-time list of allowed component types; for each type present on the entity it emits a collapsing header (using the demangled type name) and calls the matching drawComponentUI<T>() specialization.

Parameters
handleHandle to the entity to inspect.
rmThe resource manager, forwarded for components that need resource lookups.
undoStateScratch storage for undo snapshots, shared across the drawn components.
