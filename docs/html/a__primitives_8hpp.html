Detailed Description

Fundamental type aliases used throughout the Andromeda engine.

This header is the lowest-level building block of the definitions module. It re-exports GLM's vector/matrix types and the fixed-width integer types under short, engine-wide names (e.g. vec3, u32), so that the rest of the codebase does not need to depend on GLM or <cstdint> directly. Almost every other header in the project includes this file, either directly or transitively.
