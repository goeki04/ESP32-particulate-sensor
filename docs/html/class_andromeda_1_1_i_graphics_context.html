Detailed Description

Abstract interface over a graphics backend (shaders, compute, buffers, textures, framebuffers, draw calls).

All renderer code issues GPU commands through this interface rather than calling a specific API directly, so that backends (currently OpenGLContext) can be swapped without touching the renderer. Methods come in groups: shader/compute program management, drawing and pipeline state, framebuffers, textures/samplers and uniform/parameter upload.
