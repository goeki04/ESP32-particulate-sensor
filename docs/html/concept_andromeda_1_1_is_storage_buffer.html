Detailed Description

Constrains a type to the storage-buffer interface required by the engine.

Unlike IConstantBuffer (runtime polymorphism), storage buffers are used via static polymorphism: any backend type that provides create / bind / unbind / setData / getSize satisfies this concept and can be used directly (e.g. GLStorageBuffer). This keeps the hot path free of virtual calls.
