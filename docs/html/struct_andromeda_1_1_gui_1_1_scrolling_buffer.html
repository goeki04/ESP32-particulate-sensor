Detailed Description

Fixed-capacity ring buffer of 2D points for real-time scrolling plots.

Once MaxSize points have been added, new points overwrite the oldest ones in a circular fashion, so the buffer always holds the most recent window of samples without reallocating. Stores (x, y) pairs as ImVec2, where x is typically a timestamp and y the measured value.
