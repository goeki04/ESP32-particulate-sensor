Detailed Description

OpenGL-backed shader storage buffer (SSBO). Satisfies the IsStorageBuffer concept.

Move-only RAII wrapper around a GL buffer object bound to GL_SHADER_STORAGE_BUFFER. Used for read/write GPU data shared between compute and render passes (e.g. particles).
