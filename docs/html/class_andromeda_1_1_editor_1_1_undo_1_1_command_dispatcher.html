Detailed Description

Interprets a raw command record from the UndoBuffer and performs the corresponding revert.

Acts as the read side of the data-oriented undo system: it reads the CommandHeader at the front of rawData to determine the command type, casts the trailing bytes to the matching payload struct, and writes the stored "old state" back into the registry.
