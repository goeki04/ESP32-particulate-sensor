Detailed Description

Maintains the current keyboard state and dispatches input events from raw SDL events.

On each SDL event it updates a held-key bitmap and (for key/mouse button changes) translates the platform code into the engine's Keycode / MouseCode and fires the corresponding event via the EventManager. Polled state is exposed through the static isKeyHeld() so any system can query keys without subscribing to events.
