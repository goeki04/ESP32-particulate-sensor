Detailed Description

Static OpenGL helpers for creating cubemap textures and the IBL baking pipeline.

Provides upload paths for both LDR (six-face) and HDR (equirectangular) sources, allocation of empty cubemaps used as render targets during baking, and the equirectangular-to-cubemap conversion. Also exposes the fixed projection/view matrices used to render each of the six cube faces.
