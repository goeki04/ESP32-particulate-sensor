Detailed Description

Platform-agnostic key and mouse button codes used by the input system.

The numeric values intentionally mirror the USB HID usage table / SDL3 scancode values, so that input backends (e.g. SDL3) can map their native codes onto Keycode with a direct numeric cast instead of a lookup table. Gaps between value groups (e.g. between Z and D1) correspond to scancodes not currently exposed by the engine.
