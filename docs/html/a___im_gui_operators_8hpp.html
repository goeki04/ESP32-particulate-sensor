Detailed Description

Convenience arithmetic/comparison operators for ImGui's ImVec2 type.

ImGui does not define these operators by default (unless IMGUI_DEFINE_MATH_OPERATORS is set). They are provided here in the Andromeda::Gui namespace so editor code can do vector math on screen coordinates and sizes directly.
