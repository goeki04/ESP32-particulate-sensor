Detailed Description

Owns, initializes and renders all editor panels each frame; the heart of the editor UI.

Maintains a polymorphic list of EditorPanel instances and drives their lifecycle (init -> per-frame render). It implements IPanelController so that other UI elements (e.g. the menu bar) can toggle panel visibility by name. It also handles ImGui frame setup/teardown, font loading and the dockspace host window.
