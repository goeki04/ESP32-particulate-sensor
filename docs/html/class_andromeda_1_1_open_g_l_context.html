Detailed Description

Handles low-level rendering operations and state management for the OpenGL backend.

  • This class implements the graphics interface for OpenGL, managing shader programs, uniform uploads, texture binding, framebuffer operations, and render pipeline states (e.g., culling, depth testing, blending). It serves as the primary bridge between the engine's abstract rendering commands and OpenGL's API calls.

◆ allocateTexture()

void Andromeda::OpenGLContext::allocateTexture ( Texture & texture)
overridevirtual

Allocates the physical memory (VRAM) on the GPU for a texture.

This function takes a prepared texture "blueprint", generates a unique hardware ID, binds the corresponding target, and allocates the memory based on the internal format.

Warning
Because this communicates directly with the graphics API, this function MUST be called on the main render thread.
Parameters
textureReference to the pre-configured texture object. Upon successful execution, the object receives a valid API-assigned textureID.

◆ generateMipmap()

void Andromeda::OpenGLContext::generateMipmap ( TextureType type)
overridevirtual

Automatically generates the mipmap levels (LOD chains) for the active texture.

Creates halved versions of the image data down to 1x1 pixel. This is essential for performance (texture cache) and to prevent edge flickering (aliasing) on distant objects. The corresponding texture must be bound before calling this function.

Parameters
typeThe architectural texture type (e.g., 2D, Cubemap) so the RHI knows which target (e.g., GL_TEXTURE_2D) to calculate the mipmaps for.

◆ generateTexture()

Texture Andromeda::OpenGLContext::generateTexture ( u32 width,
u32 height,
SamplerState & sampler,
TextureFormat format = TextureFormat::RGBA8_UNORM )
overridevirtual

Creates the metadata for a new texture on the CPU (blueprint).

This function does NOT communicate with the GPU and does not reserve any VRAM. It merely prepares the data object. Since it is thread-safe, it is perfectly suited for preparing textures asynchronously (in the background).

Parameters
widthThe width of the texture in pixels.
heightThe height of the texture in pixels.
samplerThe desired sampler state (filtering, wrapping).
formatThe hardware-independent storage format. Default is RGBA8_UNORM (linear color space). For pure color textures, SRGB should be explicitly passed.
Returns
A configured Texture object (ID = 0, ready for allocateTexture).
