Detailed Description

Abstraction allowing UI elements (e.g. the "Window" menu) to control panel visibility without depending on the concrete GuiRenderer.

Implemented by GuiRenderer. Panels are identified by their display name, which keeps callers like the menu bar decoupled from the panel container.
