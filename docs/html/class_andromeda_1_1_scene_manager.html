Detailed Description

Holds the scene's ECS registry and editor camera, and provides entity creation/removal.

As an ISubsystem it is owned by the SystemManager. It exposes the component registry (m_Registry) that all other systems (renderer, editor, serializer) operate on, and the editor's camera state (m_EditorCamData). Entity helpers resolve mesh resources through the ResourceManager.
