Detailed Description

Per-component ImGui editor widgets used by the Inspector (DetailsPanel).

Provides drawComponentUI<T>(), a function template specialized for each editable component type (Transform, Tag, Material, ...). Edits that should be undoable snapshot the component into a std::any before the change and dispatch an undo event once the edit is committed. renderEntityComponentUI() ties this together by iterating over all supported component types on an entity.
