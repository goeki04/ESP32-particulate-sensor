Detailed Description

Owns the raw, decoded pixel data of a six-faced cubemap on the CPU, before upload to the GPU.

Pixel buffers are allocated by stb_image when loading the source images from disk and must be released via stbi_image_free(), which is why this type is move-only: copying would require either deep-copying the raw buffers or risking a double free.
