Detailed Description

Stateless utility that fills Mesh objects with the geometry of standard primitives.

All generators write directly into a caller-provided Mesh (clearing it first), producing per-vertex position, normal, UV and color, plus a triangle index buffer. Primitives are unit-sized and centered on the origin. Used by the ResourceManager to register the default Cube/Plane/Sphere meshes.

void Andromeda::PrimitiveGenerator::generateCube ( Mesh & outMesh)
inlinestatic

Generates a unit cube (side length 1, centered on the origin) with per-face normals.

Builds each of the 6 faces from 4 vertices and 2 triangles, so face normals and UVs are sharp rather than shared/smoothed across edges.

Parameters
outMeshThe mesh to populate; its existing vertex/index data is cleared first.

Generates a UV sphere of radius 0.5 centered on the origin.

Uses a latitude/longitude tessellation with a fixed resolution of 32 stacks and 32 sectors. Vertices carry normalized normals and spherical UV coordinates.
